✅ Resposta Prática sobre Publicação e Instalação: No Docker, não é necessário instalar nada manualmente dentro do sistema operacional do servidor. Você apenas coloca os arquivos na pasta mapeada do host e executa o comando docker compose up -d. O Docker baixa as imagens, instala os drivers PostgreSQL (PDO_PGSQL), configura o Traefik com SSL automático e publica o site em menos de 60 segundos.

1. Arquitetura da Publicação do Contêiner

Internet / Usuários (HTTP :80 / HTTPS :443) │ ▼ [ Contêiner Traefik ] ──► Emite e renova certificado SSL Let's Encrypt automático │ ▼ (Rede interna: eloizio_network) [ Contêiner Web: eloizio-hub-web ] (Apache + PHP 8.2) │ Volume mapeado: ./php-dist ◄───► /var/www/html (Arquivos do Site) │ ▼ (Porta interna :5432) [ Contêiner Banco: eloizio-postgres ] (PostgreSQL 16) │ Volume persistente: eloizio_postgres_data (Clientes, Conversas, Camilla)

2. Onde os Arquivos Ficam Publicados no Servidor

No seu servidor (VPS Ubuntu ou Debian), crie a seguinte estrutura de pastas:

/var/www/grupoeloizio/
├── docker-compose.yml     # Orquestrador dos contêineres
├── Dockerfile             # Imagem do Apache + PHP 8.2 com PDO_PGSQL
├── .env                   # Senhas e chaves secretas do sistema
├── letsencrypt/           # Pasta onde o Traefik grava o certificado SSL (acme.json)
└── php-dist/              # ◄─── PASTA ONDE FICAM OS ARQUIVOS PUBLICADOS DO SITE
    ├── index.php          # Página inicial do Mini Shopping e Hub
    ├── admin.php          # Painel Administrativo
    ├── api.php            # Roteador da API REST (/api/health, /api/services, etc.)
    ├── config.php         # Conexão com o PostgreSQL e Fallback JSON
    ├── .htaccess          # Regras do Apache para URLs amigáveis
    ├── install.php        # Assistente automático de criação de tabelas
    ├── postgres_schema.sql# Estrutura DDL das tabelas
    └── data/              # Cache local e storage JSON de segurança

3. Arquivo: docker-compose.yml Completo

Crie o arquivo /var/www/grupoeloizio/docker-compose.yml com o conteúdo abaixo:

version: '3.8'

services:
  # ----------------------------------------------------------------------------
  # 1. TRAEFIK - REVERSE PROXY COM SSL AUTOMÁTICO (LET'S ENCRYPT)
  # ----------------------------------------------------------------------------
  traefik:
    image: traefik:v2.10
    container_name: eloizio-traefik
    restart: unless-stopped
    security_opt:
      - no-new-privileges:true
    ports:
      - "80:80"     # Redireciona HTTP para HTTPS automaticamente
      - "443:443"   # HTTPS seguro com certificado
    command:
      - "--api.dashboard=false"
      - "--providers.docker=true"
      - "--providers.docker.exposedbydefault=false"
      - "--entrypoints.web.address=:80"
      - "--entrypoints.web.http.redirections.entrypoint.to=websecure"
      - "--entrypoints.web.http.redirections.entrypoint.scheme=https"
      - "--entrypoints.websecure.address=:443"
      - "--certificatesresolvers.letsencrypt.acme.tlschallenge=true"
      - "--certificatesresolvers.letsencrypt.acme.email=mecanicoeloizio@gmail.com"
      - "--certificatesresolvers.letsencrypt.acme.storage=/letsencrypt/acme.json"
    volumes:
      - "/var/run/docker.sock:/var/run/docker.sock:ro"
      - "./letsencrypt:/letsencrypt"
    networks:
      - eloizio-net

  # ----------------------------------------------------------------------------
  # 2. APACHE + PHP 8.2 COM PDO_PGSQL ATIVADO
  # ----------------------------------------------------------------------------
  web:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: eloizio-hub-web
    restart: unless-stopped
    depends_on:
      postgres:
        condition: service_healthy
    volumes:
      # ONDE OS ARQUIVOS FICAM: Mapeia a pasta do host para dentro do contêiner
      - ./php-dist:/var/www/html
      - ./php-dist/data:/var/www/html/data
    environment:
      - DB_HOST=postgres
      - DB_PORT=5432
      - DB_NAME=grupoeloizio
      - DB_USER=postgres
      - DB_PASS=eloizio_postgres_sec_2026
      - CAMILLA_WHATSAPP=5521996134073
      - ECOSYSTEM_DOMAIN=grupoeloizio.com.br
    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.eloizio-web.rule=Host(`grupoeloizio.com.br`, `www.grupoeloizio.com.br`)"
      - "traefik.http.routers.eloizio-web.entrypoints=websecure"
      - "traefik.http.routers.eloizio-web.tls.certresolver=letsencrypt"
      - "traefik.http.services.eloizio-web.loadbalancer.server.port=80"
      - "traefik.http.middlewares.eloizio-compress.compress=true"
      - "traefik.http.routers.eloizio-web.middlewares=eloizio-compress"
    networks:
      - eloizio-net

  # ----------------------------------------------------------------------------
  # 3. POSTGRESQL 16 (BANCO DE DADOS UNIFICADO)
  # ----------------------------------------------------------------------------
  postgres:
    image: postgres:16-alpine
    container_name: eloizio-postgres
    restart: unless-stopped
    environment:
      POSTGRES_DB: grupoeloizio
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: eloizio_postgres_sec_2026
      PGDATA: /var/lib/postgresql/data/pgdata
    volumes:
      - postgres_data:/var/lib/postgresql/data
      - ./php-dist/postgres_schema.sql:/docker-entrypoint-initdb.d/init.sql:ro
    ports:
      - "127.0.0.1:5432:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres -d grupoeloizio"]
      interval: 5s
      timeout: 5s
      retries: 5
    networks:
      - eloizio-net

volumes:
  postgres_data:
    name: eloizio_postgres_data

networks:
  eloizio-net:
    name: eloizio_network
    driver: bridge

4. Arquivo: Dockerfile (Apache + Drivers)

Crie o arquivo /var/www/grupoeloizio/Dockerfile:

FROM php:8.2-apache

# Instalação das extensões necessárias (PostgreSQL, cURL, GD, ZIP)
RUN apt-get update && apt-get install -y --no-install-recommends \
    libpq-dev \
    libcurl4-openssl-dev \
    libpng-dev \
    libjpeg-dev \
    libfreetype6-dev \
    libzip-dev \
    zip \
    unzip \
    curl \
    && docker-php-ext-configure gd --with-freetype --with-jpeg \
    && docker-php-ext-install -j$(nproc) \
        pdo \
        pdo_pgsql \
        pgsql \
        curl \
        gd \
        zip \
    && apt-get clean \
    && rm -rf /var/lib/apt/lists/*

# Habilita o mod_rewrite do Apache
RUN a2enmod rewrite headers

WORKDIR /var/www/html

EXPOSE 80

CMD ["apache2-foreground"]

5. Passo a Passo Completo de Instalação no Servidor

Etapa 1: Conectar no seu Servidor VPS via SSH

ssh root@seu_ip_do_servidor

Etapa 2: Instalar o Docker e o Docker Compose (se ainda não tiver)

apt update && apt upgrade -y
curl -fsSL https://get.docker.com | sh
docker --version
docker compose version

Etapa 3: Criar a Pasta do Projeto e Subpastas

mkdir -p /var/www/grupoeloizio/letsencrypt
mkdir -p /var/www/grupoeloizio/php-dist
touch /var/www/grupoeloizio/letsencrypt/acme.json
chmod 600 /var/www/grupoeloizio/letsencrypt/acme.json

Etapa 4: Subir os Arquivos do Site

Transfira o arquivo compactado site.zip para /var/www/grupoeloizio/ e descompacte:

cd /var/www/grupoeloizio
unzip site.zip -d php-dist/
chmod -R 775 php-dist/
chown -R 33:33 php-dist/data/  # Permissão para o usuário www-data do Apache

Etapa 5: Iniciar Todos os Contêineres

Execute um único comando para construir e inicializar a stack inteira:

cd /var/www/grupoeloizio
docker compose up -d --build

Etapa 6: Verificar se os Contêineres Estão Rodando

docker compose ps

Você deverá ver os 3 contêineres com status Up (healthy):

  • eloizio-traefik - Up (portas 80, 443)
  • eloizio-hub-web - Up (porta 80)
  • eloizio-postgres - Up (healthy, porta 5432)

6. Comandos Úteis de Manutenção Diária

Ação Desejada Comando a Executar
Ver logs em tempo real do Apache/PHP docker compose logs -f web
Ver logs de certificados SSL do Traefik docker compose logs -f traefik
Reiniciar contêineres sem perder dados docker compose restart
Fazer Backup do Banco PostgreSQL docker exec -t eloizio-postgres pg_dump -U postgres grupoeloizio > backup_$(date +%F).sql
Restaurar Backup do Banco cat backup.sql | docker exec -i eloizio-postgres psql -U postgres -d grupoeloizio
Atualizar arquivos do site Basta colar os novos arquivos em /var/www/grupoeloizio/php-dist/. Atualização imediata!
